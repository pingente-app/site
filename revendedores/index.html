Guia de compra

Compre a tag certa

O erro nº 1 de quem começa é comprar o modelo errado. Só este funciona no app:

✓ Compatível

Gicisky 2,1" — BWR · 250×122 px · BLE

  • ✓ o anúncio diz "BWR" ou "B/W/R"
  • ✓ tamanho exatamente 2,1"
  • ✓ resolução 250×122
  • ✓ Bluetooth (BLE), não só NFC

✕ Não serve

parecida, mas errada

  • ✕ 2,13" BW — sem o canal vermelho
  • ✕ 2,9" ou 4,2" — não cabe no case
  • ✕ só NFC — o app não conecta
  • ✕ etiqueta de loja (ESL) sem BLE aberto
Valide cada tag antes de anunciar: Conecta no app por Bluetooth Recebe uma face de teste Mostra preto, branco e vermelho Ativação confirmada no app
